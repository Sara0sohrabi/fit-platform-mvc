# Gymmap — Mobile App Wireframe

## Reference

This wireframe is based on the supplied Gymmap mobile-app design reference.

## Core screens

1. Onboarding
2. Create Account
3. Location Access
4. Home
5. Nearby Gyms
6. Gym Detail
7. Special Offers
8. Profile

## Main product flow

Onboarding → Account creation / Login → Location permission → Home → Nearby gyms / Offers → Gym detail → Directions / Booking → Profile.

## UI direction

- Gym discovery around the user's location
- Gym, class, offer and workshop discovery
- Bookings and user activity
- Fitness progress and profile
- Purple/indigo primary action language from the supplied reference
- Mobile-first layout with bottom navigation

> Note: This document describes the wireframe structure. The supplied visual reference remains the source of truth for the final UI styling.
